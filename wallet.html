Payments

Wallet & top-up

Saari khareedari wallet balance se hoti hai. Minimum deposit $1 hai. Maximum shuruaati taur par $500 hai, jo badal sakta hai.

Top-up ke tarike

  • UPI (manual): UPI par pay karo, UTR bhejo, admin approve karta hai.
  • UPI (auto): payment email verify hoti hai aur balance apne aap add hota hai.
  • Binance Pay: checkout link se payment, status automatic.
  • USDT (BEP20): wallet address par transfer, blockchain se verify.
  • Binance ID (manual): Binance ID par transfer, admin approve karta hai.

Card details ya passwords is website par kabhi nahi maange jaate.
