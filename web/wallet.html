Wallet & top-up

Saari khareedari wallet balance (USD) se hoti hai. Top-up karne ke liye account mein login karke Wallet & top-up tab kholo.

Wallet kholo

Top-up ke tarike

  • UPI: amount chuno, UPI par pay karo, 12-digit UTR bhejo. Admin check karke approve karta hai.
  • Binance ID: Binance ID par transfer karo, transaction/order ID bhejo. Admin approve karta hai.
  • USDT (BEP20): diya gaya exact amount address par bhejo, transaction hash daalo. Blockchain se apne aap verify hoti hai.

Card details ya passwords is website par kabhi nahi maange jaate. Ek hi UTR ya transaction hash do baar use nahi ho sakta.
